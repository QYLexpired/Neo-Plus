## 说明
- Neo+是[Neo主题](https://github.com/QYLexpired/Neo)的配套插件，为Neo主题提供配色和样式扩展，仅在使用Neo主题时生效
- 插件不向文档写入或修改任何数据，仅进行外观修改，可随时启用或卸载而不影响任何笔记内容
- 注意：卸载Neo+时，所有插件相关配置均会删除（包括自定义图片配置、特性开关和参数配置等），如需保存，可备份工作空间的`/data/storage/petal/Neo-Plus/config`文件
- 插件内所有功能/特性都具有完整的生命周期，仅在开启时消耗性能，其中部分特性对性能消耗可能较大，需根据设备情况选择性开启
- 更多说明可查看Neo主题介绍页
