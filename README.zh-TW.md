## 說明
- Neo+是[Neo主題](https://github.com/QYLexpired/Neo)的配套插件，為Neo主題提供配色和樣式擴展，僅在使用Neo主題時生效
- 插件不向文檔寫入或修改任何數據，僅進行外觀修改，可隨時啟用或卸載而不影響任何筆記內容
- 注意：卸載Neo+時，所有插件相關設定均會刪除（包括自訂圖片設定、功能開關和參數設定等），如需保留，可備份工作空間中的`/data/storage/petal/Neo-Plus/config`檔案
- 插件內所有功能/特性都具有完整的生命週期，僅在開啟時消耗效能，其中部分特性對效能消耗可能較大，需根據設備情況選擇性開啟
- 更多說明可查看Neo主題介紹頁
